Tiki overlay controller

Notre Dame–inspired flip typography for OBS and Moblin. Off-stream only — do not add this page as a browser source.

This is a URL builder, not live remote control. Changing the fields below updates the preview and the generated overlay URL on this page only. It does not push changes to a source that is already running on stream. To apply new wording, timing, position, scale, or canvas size, copy the new overlay URL and paste it into the OBS or Moblin browser source (or reload that source after you edit the URL).

Live preview of the generated URL

The checkerboard is only in this preview, so you can see the transparent page behind the letters. Set your OBS / Moblin browser source width and height to the same values as canvas width (w) and height (h). The flip runs on a CSS animation inside the overlay page; this preview reloads when you change a field so you can check the result before copying the URL.
